网页端使用说明

本软件是一个用于PDF单线图查看、标注、OCR识别和结果导出的网页端工具。下面只说明网页端的使用方法和环境配置。

一、环境配置

1. 基础环境
- 安装 Node.js。
- 安装 npm。
- 准备 OCR 服务。
- 准备 MinerU 服务。

2. 配置文件
- 开发态使用 public/app-config.json。
- 生产态使用 build_prod/app-config.json。

常见配置项包括：
- ocr_server_host
- ocr_server_port
- mineru_base_url
- ocr_backend
- ocr_backend_exe_path

说明：
- 3004 读取 public/app-config.json。
- 3005 读取 build_prod/app-config.json。
- 两边的地址可以不同。

二、使用方法

1. 开发预览
- 执行 npm install。
- 执行 npm start。
- 访问 http://127.0.0.1:3004/。

2. 生产预览
- 执行 npm run build。
- 执行 npm run serve-prod。
- 访问 http://127.0.0.1:3005/。

3. 常用操作
- 打开 PDF 文件。
- 调整 OCR 配置。
- 查看 OCR 和 MinerU 状态。
- 执行识别。
- 导出结果。

三、PDF渲染功能

本软件使用 react-pdf 封装 pdf.js 实现 PDF 渲染，渲染效果做了针对性优化。

功能特点：
- 支持单页和连续滚动两种视图模式。
- 支持 Ctrl 加鼠标滚轮进行缩放，缩放范围较大，便于查看细节。
- 支持 PageUp、PageDown、Home、End 等键盘导航。
- 支持右键拖拽浏览大图。
- 启用了字体平滑和图像渲染优化，提升阅读清晰度。

四、标注功能系统

本软件支持多种标注形状和工程化标注方式，适合焊口预制和图纸标注。

1. 标注框样式
- 圆形框。
- 菱形框。
- 矩形框。
- 车间焊缝样式。
- 现场焊缝样式。
- 无边框纯文字标注。

2. 标注框大小
- 标注框按统一几何规则计算，保证不同形状的视觉尺度一致。
- 不同标注形状在外接范围上保持统一，便于图纸管理。

3. 文本处理
- 会根据文本长度自动调整显示大小。
- 对中英文文本做了适配处理。
- 在部分模式下会自动去掉括号字符，减少显示干扰。

4. 标注规则
- 支持前缀和后缀规则。
- 支持起始编号自定义。
- 支持自动递增。

5. 标注编辑
- 支持拖拽移动。
- 支持双击编辑。
- 支持 Delete 删除、Escape 取消等快捷键。
- 支持撤销和重做。

6. 材料编号绑定
- 标注可以绑定材料编号。
- 支持自动弹出材料编号输入。
- 支持标注与材料信息联动。

7. 导出功能
- 支持导出为 PDF。
- 支持导出焊口表。
- 支持导出 Excel 格式。
- 导出内容可包含序号、PDF页码、焊口、备注、材料编号等信息。

五、OCR识别功能

OCR 功能采用前后端分离方式实现，前端通过网页界面操作，后端通过 OCR 服务和 MinerU 进行识别。

1. 区域类型
- 材料表区域：用于识别主表格内容。
- 管线号区域：用于识别管线编号。
- 图号区域：用于识别图纸编号。
- 页码区域：用于识别页码信息。

2. 工作方式
- 先在页面上选择识别区域。
- 再将区域图像送入 OCR 服务或 MinerU。
- 最后将识别结果回填到页面和导出数据中。

3. 模板导入
- 支持导入模板。
- 模板可以恢复材料表区域、管线号区域、分割线等设置。

4. 识别结果处理
- 支持表格解析。
- 支持文本提取。
- 支持数据清洗。
- 支持导出 Excel。

六、焊口、支架和阀门功能

1. 焊口功能
- 支持焊口标注。
- 支持焊口表与材料表绑定。
- 支持焊口信息导出。

2. 支架功能
- 可自动识别支架编号。
- 支持批量自动标注。
- 支持支架编号清洗和排序。
- 支持按页面统一管理。

3. 阀门功能
- 可识别阀门编号。
- 支持阀门单独标注。
- 支持阀门统计和显示。
- 阀门与支架分开处理，便于工程管理。

七、PDF内置旋转处理

本软件支持自动识别 PDF 页面旋转角度，并对标注和坐标做同步转换。

特点：
- 支持 0、90、180、270 度旋转。
- 标注在旋转页面上仍可正常显示。
- 文字方向会自动调整，保证可读性。

八、常见问题

1. OCR 服务未运行
- 先检查 OCR 服务地址和端口是否可访问。

2. MinerU 服务未运行
- 先检查 MinerU 的健康检查地址是否正常返回。

3. 页面显示异常
- 先确认 3004 是否读取了开发态配置。
- 再确认 3005 是否读取了生产态配置。
- 同时检查 OCR 服务和 MinerU 服务地址是否正确。

九、备注

- 3004 是开发态网页端。
- 3005 是生产态网页端。
- 两者的配置文件和服务地址可以分别设置。
- 如果要协同编辑或迁移到其他机器，先确认 OCR 和 MinerU 的运行环境是否已经准备好。
