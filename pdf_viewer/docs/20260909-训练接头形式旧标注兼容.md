# 训练样本接头形式旧标注兼容

## 原因与修改

训练标签原先只从 jointTypeText、jointType 和 weldData 对应字段读取接头形式。旧可编辑 PDF 中存在大量独立字段为空、接头形式实际写在分栏圆形 topText 中的情况，例如 `1"BW`、`6"SW`、`1"OL`。标签构建时因此省略 jointType，后续上传只能发送缺字段的标签。

已在 `src/utils/weldAiFusion.js` 的 getConfirmedJointType 中增加局部兼容：独立字段仍优先；缺失时，仅从该焊口自己的分栏圆形上半栏提取明确的接头文案。兼容组合寸径、小数/分数寸径、常见引号、无引号组合、旧式 `"BW6`，以及常见接头缩写和对接/承插焊文字。纯寸径、长度备注和不确定文字保持不填，不读取附近标注或跨页猜测。

共享标签构建函数用于在线上传、训练包导出和完整度统计，因此三者同时生效。没有改动焊点坐标、编号、模型接口或远端程序。

## 使用

刷新新版后重新点击“确认训练样本”，重新构建该页标签。只重试之前缺字段的缓存包不会补出新字段。按部署端交接约定，相同 project/sampleId 重新提交覆盖对应样本；不要为了补字段先重新导出/改名 PDF，以免改变样本身份。
