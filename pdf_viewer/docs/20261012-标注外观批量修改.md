# 标注外观批量修改

标注管理的“当前页字体”下方增加“标注外观”，使用现有批量更新及撤销命令，整次应用只有一条撤销记录。

- 范围：当前页、当前页已选、指定多页、所有页；默认当前页。指定多页可填写 `1,3-5`，非法或越界页码禁止应用。已选范围为空时不回退到整页。
- 可按原框形筛选；例如只修改圆形，不影响同页的其他框型。
- 框形默认保持不变；勾选“修改颜色”后颜色才参与更新。支持单独改框形、单独改颜色及同时修改。
- 提供真正的方形（`rectangle`），并在主工具栏、单个标注编辑及管理表格的框形选项中加入方形；菱形仍使用 `diamond`。
- 应用按钮显示符合条件的标注数量。文字和支架标注按范围处理，箭头等其他类型不处理；编号、位置、管线号、材料绑定等字段保留。
- 圆形、分割圆、菱形转为方形等使用保存尺寸的框型时，读取对应 PDF 页尺寸，将原有 A3 打印 10 mm 框尺寸写入标注，避免旧尺寸字段导致外观突然变大。长方形恢复文字适配规则。转换成分割圆补齐上下字号，保留已有上下文字。
- 页尺寸读取失败时不提交任何更新；读取期间重复点击不会重复提交；切换 PDF 后旧请求不写入新文档。

将红色圆形改成蓝色方形：选择范围，原框形选“仅圆形”，修改后的框形选“方形”，勾选“修改颜色”并选蓝色，核对数量后点击“应用外观”。需要恢复时使用 Ctrl+Z。

验证：7 组相关测试、88 项测试通过；生产构建成功；真实 Edge 浏览器验证了 960/600/480px 宽度下的布局及一次性将第 1—2 页圆形变为蓝色方形的交互。修改数据仅包含外观字段，由现有命令负责撤销和重做。
