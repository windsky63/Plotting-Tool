# 训练样本管线号

- 每页仅对应一个管线号。标签优先读取标注自身的管线号；缺失时复用该页已经保存的管线号区域识别结果，上传和导出阶段不重新调用 OCR。
- 每个 `labels[]` 对象分别写入 `pipelineNumber`、`pipelineNumberRaw` 和 `pipelineNumberSource`，不只写在请求根级。
- 管线号会去除空白及不可见字符并统一大写，保留连字符、斜杠和前导零；纯数字结果仍按无效识别处理。
- 自动识别值先标记为 `inferred`；用户点击“确认并提交”后变为 `ocr_confirmed`。右侧人工修改为 `user_confirmed`，已有业务数据为 `business_data`。
- 管线号缺失时不猜测，确认窗口会显示缺失数量和页码；其余已有字段仍可导出。
- 请求继续使用 `/api/weld-ai/training-samples/confirm-leader-end`，保留图片、焊口号、接头形式和引线端点，增加 `pipelineNumberSchemaVersion: 1` 与空的 `recognitionArea`。
- 未被远端接受的旧离线请求因无法安全补齐管线号会被清理；已有远端回执的请求保留并继续轮询。相同 `sampleId` 再次确认可覆盖旧样本。
