# 批量组件标题与悬停提示

标注外观、已有标注字号和批量内容统一使用同一个标题组件，字体沿用标注外观的 12px、600 字重，并统一字体族及颜色。

操作说明改为标题上的鼠标悬停提示，也支持键盘聚焦查看。批量内容提示包含材料表寸径来源、默认值、选中项、焊口号范围及空白项保持原值等说明。自动统计范围的说明和状态也移至标题提示。页码输入错误仍在输入区域显示，避免隐藏必要的校验信息。

标注外观的“原框形”和“新框形”改为选择框左侧的前置标签，类似字号输入框的附加标签；指定多页时页码标签也放在输入框前。范围选择不显示额外标题，只保留下拉框。

验证：两个现有组件测试套件、4 项测试通过；真实 Edge 浏览器确认三个标题的计算字体样式一致，三个标题均显示相应悬停说明，原框形/新框形标签在框前且无额外范围标题。差异检查通过。仅做本地构建验证，未生成部署包或更新服务器。
