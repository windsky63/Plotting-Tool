# 网页端使用说明

本文只说明网页端的使用方法和环境配置。

## 1. 环境配置

### 1.1 基础环境

- 安装 `Node.js`
- 安装 `npm`
- 准备 OCR 服务
- 准备 MinerU 服务

### 1.2 配置文件

网页端配置文件是：

- 开发态：`public/app-config.json`
- 生产态：`build_prod/app-config.json`

常见配置项：

- `ocr_server_host`
- `ocr_server_port`
- `mineru_base_url`
- `ocr_backend`
- `ocr_backend_exe_path`

说明：

- `3004` 读取 `public/app-config.json`
- `3005` 读取 `build_prod/app-config.json`
- 两边地址可以不同

## 2. 使用方法

### 2.1 开发预览

```bash
npm install
npm start
```

打开后访问：

```text
http://127.0.0.1:3004/
```

### 2.2 生产预览

```bash
npm run build
npm run serve-prod
```

打开后访问：

```text
http://127.0.0.1:3005/
```

### 2.3 常用操作

- 打开 PDF 文件
- 调整 OCR 配置
- 查看 OCR / MinerU 状态
- 执行识别
- 导出结果

## 3. 常见问题

### 3.1 OCR 服务未运行

先检查 `ocr_server_host:ocr_server_port` 是否可访问。

### 3.2 MinerU 服务未运行

先检查 `mineru_base_url/health` 是否正常返回。

### 3.3 页面显示异常

优先确认：

- `3004` 是否读取了开发态配置
- `3005` 是否读取了生产态配置
- OCR 服务和 MinerU 服务地址是否配置正确
