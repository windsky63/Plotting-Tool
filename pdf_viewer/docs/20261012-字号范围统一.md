# 字号范围统一

原管理面板同时显示“已有标注字号”和“所有页圆形/分栏圆形/菱形字体”。前者直接保存输入数值，后者使用 `scaleAnnotationValue` 按页面尺寸换算；相同输入在同一页可能产生不同的实际字号。这不是选择范围的差别，而是计算规则不一致。

将两套控件和处理函数合并为一个“已有标注字号”组件，明确选择当前页、当前页已选、指定多页或所有页；各范围共用同一页尺寸读取和字号换算函数。保留 A3 打印基准，新增标注的默认字号不受影响。无当前页选择时，“当前页已选”不自动回退为整页。

只有普通框型（包括圆形、方形）时显示一个“字号”；只有分割圆时显示“上/下”；混合框型时显示上下字号和普通字号。范围、页码、处理数量和应用按钮在同一区域。原“所有页”单独控件移除。

字号应用仅修改相应字号字段，不改变框形、颜色、焊口号或位置，仍使用一条批量撤销命令。页面读取失败时不提交；切换 PDF 后不提交旧请求。文本较长时仍沿用原有框内字体适配规则。

验证：5 组相关测试、46 项通过；实际管理面板浏览器回放中，三个圆形标注使用同一数值分别应用“当前页”和“所有页”，更新结果完全一致；普通圆形只出现一个字号框，旧所有页字号区不存在。生产构建成功，差异检查通过。
