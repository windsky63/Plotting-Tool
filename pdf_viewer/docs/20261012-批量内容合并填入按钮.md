# 批量内容合并填入按钮

批量寸径及接头功能是原有功能，用户提供的 `releases/落图工具源码_20260920_135322.zip` 中已包含“批量内容”“填入寸径”“填入接头”。本次仅合并应用入口。

合并为一个“填入”按钮，一次构造寸径和接头的更新，通过现有批量命令提交，整次操作只需撤销一次。只填写一项时，另一项保持原值；两项均为空时提示填写。所选焊口和焊口号范围同时作用于两个字段，避免合并后接头误改范围外标注。

保留多管子寸径保护：存在多种寸径且没有选择标注时，填入寸径必须指定范围；仅填接头不受该限制。无效范围、空匹配不会产生部分更新；相同内容不创建重复命令。

验证：3 组测试、32 项通过，覆盖同时填入、只填一项、范围、多寸径保护和无效输入。生产构建用于本地验证，未生成部署包或更新服务器。
