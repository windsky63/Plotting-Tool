# 方形引线连接与字号说明

方形边框使用 `rectangleHalfSide` 绘制，旧引线却将它乘以 `sqrt(2)` 后作为连接点范围；部分渲染路径还按外接圆半径截断引线，导致端点在方形外部。

统一为引线方向与实际方形边缘的交点，使用真实半边长。修改已覆盖 PDF 查看器的已有标注、绘制预览和拖动预览、独立标注组件及 PDF 导出。水平、垂直、斜向连接均落在边缘；起点已在方形内部时，不将线继续延伸到起点之外。

“当前页字体”保留并改名为“已有标注字号”，显示实际处理范围：当前页已选或当前页全部。应用按钮改为“应用字号”，补充说明：上/下用于分割圆上下文字，普通用于方形、圆形等其他框型；不修改新建标注的默认字号。批量外观控制框形和颜色，两者功能独立。

验证：6 组相关测试、50 项通过，包括三种方向的实际 SVG 端点与框边一致，已有外观更新和拖动逻辑回归通过。生产构建用于本地检查，未生成部署包或更新服务器。
