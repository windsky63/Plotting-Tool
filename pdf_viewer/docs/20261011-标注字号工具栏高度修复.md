# 标注字号工具栏高度修复

进入标注模式或选中标注后，字号控件外层 `AnnotationTools` 的上下内边距各为 8px，选中标注容器还有额外边框，导致主工具栏变高。

将容器高度统一为 32px，上下内边距设为 0；内部选择框及选择器也显式统一为 32px，避免 Ant Design 小尺寸样式覆盖。批量选择提示使用内嵌描边，保留蓝色外观并避免增加高度。字号选项和字体修改逻辑保留。

验证：8 组相关测试、81 项测试通过；生产构建成功；真实 Edge 浏览器在 1920、1440、1000px 宽度下检查了 27 个场景，覆盖普通标注、分割圆、管段框、单独选择、同时开启标注模式与批量选择，以及混合类型提示。各场景的主工具栏高度与默认状态一致，容器及选择框均为 32px。

部署包为 `releases/luotu-web-20261011-frame-rollback-font-toolbar.zip`，包含此前完成的框大小局部回退及现有其他修改。本包按现有网页更新包格式生成，替换服务器 `pdf_viewer/build_prod` 内的网页文件，保留原有 `app-config.json` 和运行数据；具体步骤见包内 `更新说明.txt`。ZIP 和网页文件均已校验。
