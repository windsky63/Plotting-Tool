# 远端焊点 AI 服务包使用说明

## 用途

本服务部署在有 NVIDIA GPU 的内网电脑，用于从图纸焊点区域识别焊点中心候选并返回红点坐标。

它不会生成焊口编号、接头形式、管径或最终标注；这些仍由落图工具现有规则和人工确认处理。模型未训练或服务不可用时，落图工具自动继续使用原有规则识别。

## 远端首次安装

1. 将整个 `remote_weld_ai` 文件夹复制到远端电脑，例如 `D:\remote_weld_ai`。
2. 在该目录打开 PowerShell，确认 NVIDIA 驱动可用：`nvidia-smi`。
3. 创建环境并安装依赖：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

4. 指定模型和样本数据目录后启动服务：

```powershell
$env:WELD_AI_DATA_DIR = 'D:\weld-ai-data'
uvicorn app:app --host 0.0.0.0 --port 8767
```

5. 在落图电脑访问 `http://远端电脑IP:8767/api/weld-ai/health`。无权重时应看到 `available: true`、`modelLoaded: false`；这属于正常待训练状态。
6. 在落图工具生产目录的 `app-config.json` 配置：

```json
{
  "weld_ai_server_url": "http://远端电脑IP:8767"
}
```

刷新小程序后，在多页处理中手动开启“远端 AI 焊点辅助”。默认关闭。

## 样本与训练

1. 用落图工具打开人工核对完成的 PDF，点击“确认焊点训练样本”。只提交已确认的普通焊口；支架、静电接地和非焊口标注不会作为正样本。
2. 样本会保存到 `D:\weld-ai-data\confirmed_samples`。同一 PDF 页重新确认会覆盖旧样本。
3. 收集至少 300 页、3,000 个焊点、至少 3 个不同 PDF 后，运行：

```powershell
.\.venv\Scripts\python train.py --data D:\weld-ai-data\confirmed_samples --output D:\weld-ai-data\models\weld-center-v1.pt
```

4. 训练完成后重启 8767 服务。健康检查出现 `modelLoaded: true` 后，选择未参与训练的 PDF 灰度验证候选红点；AI 独有候选必须人工采纳，不能直接生成最终标注。

## 注意事项

- 训练不要与在线推理共用同一个服务进程；训练期间保持 8767 推理服务可用。
- 8767 仅在内网开放，并在 Windows 防火墙放行来自落图电脑的访问。
- 每次训练保留模型权重、训练日志和样本目录备份；新模型效果不佳时，将权重文件换回上一稳定版本并重启服务。
