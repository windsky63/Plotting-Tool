# PDF单线图焊口预制标注工具

一个专业的PDF单线图焊口预制标注工具，基于Electron和React开发，具有媲美WPS和Word的清晰度和丰富的标注功能，专为焊接工程领域设计。

## 功能特性

### 📖 PDF查看
- 高质量PDF渲染，清晰度媲美WPS、Word等专业软件
- 支持高DPI显示器的优化渲染
- 流畅的页面切换和缩放
- 缩略图导航
- 全文搜索功能

### ✏️ 标注功能
- **高亮标注** - 标记重要内容
- **下划线** - 强调文本
- **删除线** - 标记已完成或错误内容
- **几何图形** - 矩形、圆形等形状标注
- **箭头和线条** - 指向性标注
- **文字批注** - 添加文字说明
- **颜色选择** - 多种颜色可选
- **撤销/重做** - 支持操作回退

### 🔍 搜索功能
- 全文搜索
- 搜索结果高亮显示
- 快速导航到搜索结果

### 🎨 现代化界面
- 简洁美观的现代UI设计
- 响应式布局
- 可折叠侧边栏
- 工具栏快捷操作

## 技术栈

- **Electron** - 跨平台桌面应用框架
- **React 18** - 现代化前端框架
- **PDF.js** - Mozilla开发的PDF渲染引擎
- **Ant Design** - 企业级UI组件库
- **styled-components** - CSS-in-JS样式解决方案

## 安装和运行

### 安装依赖
```bash
npm install
```

### 开发模式运行
```bash
npm run electron-dev
```

### 构建生产版本
```bash
npm run build
npm run electron-pack
```

### Web 端构建与发布说明
```bash
# 仅构建默认前端产物
npm run build

# 真正发布 3005 端口生产版本（Windows）
deploy.bat
```

- `npm run build` 只会更新默认的 `build/` 目录，便于本地测试，不会直接影响当前 3005 端口用户。
- 3005 端口的生产前端实际读取的是 `build_prod/`。
- 只有执行 `deploy.bat` 时，才会将最新的 `build/` 复制到 `build_prod/`，并重启 3005 端口上的生产服务。

## 使用说明

### 打开PDF文件
1. 点击工具栏的"打开"按钮
2. 选择要查看的PDF文件
3. 或使用菜单栏的"文件" → "打开PDF"快捷键 `Ctrl+O`

### 标注功能
1. 点击工具栏的"标注"按钮进入标注模式
2. 选择标注工具（高亮、下划线、矩形等）
3. 选择标注颜色
4. 在PDF页面上拖拽进行标注
5. 在侧边栏查看和管理所有标注

### 搜索功能
1. 在工具栏搜索框中输入关键词
2. 按回车键开始搜索
3. 使用前进/后退按钮浏览搜索结果
4. 在侧边栏的搜索标签页查看所有结果

### 导航功能
- 使用工具栏的页面导航按钮
- 在侧边栏的缩略图标签页点击页面
- 使用页码输入框快速跳转

## 高质量渲染特性

本PDF查看器采用了多项技术来确保渲染质量：

1. **PDF.js引擎** - 使用与Firefox浏览器相同的PDF渲染引擎
2. **高DPI支持** - 针对高分辨率显示器优化
3. **图像渲染优化** - 使用crisp-edges等CSS属性优化文字清晰度
4. **抗锯齿处理** - 启用字体平滑处理
5. **矢量渲染** - 支持矢量图形的完美缩放
